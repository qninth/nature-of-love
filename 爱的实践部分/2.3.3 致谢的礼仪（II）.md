# 2.3.3 致谢的礼仪 (II)

> Posted by 小鬼 on 七 23rd, 2013 in 2.3 致谢

我们继续讲东西，上次我们说到致谢的礼仪：第一条，是注意私密性——这实际上说的是小心翼翼的保证对方的自由;第二条，是要注意庄重性——对方允许你表达谢意，给了你表达的机会，你就要庄重的对待。

那么庄重性如何保证？庄重性最重要的就是准确和直接——你要清楚明白的说清楚你在感谢什么——不要用任何暗示、比喻、眉目传神、甚至不说话“相信他自然明白”之类的含糊手段。很多人喜欢这么做：要感谢对方，于是找别的借口请对方吃饭或者默默给别人好处(比如默默的在投票的时候投这个人一票)，然后就在自己心里告诉自己说：“啊，我已经谢过了”;还有的会请人吃饭，热烈愉快的聊天，直到饭局结束，他拍拍人家的背，“上次的事情谢谢你哈”……“上次的事情”？什么事情？是说我之前救了你一命那件事，还是昨天下午老板骂你我帮你说话的事？现在这顿饭是在对哪件事致谢？你的意思是你的命就值一顿饭么？还是说这顿饭是在报答昨天帮你说话而救命那事大家不如忘记？

致谢，一定要清楚明白的告诉对方目前的谢意是针对什么。一样归一样，这是庄重性最基本的要求——在这一方面含糊其辞、敷衍了事甚至蒙混过去，那么这就不是致谢，而是试图**应付致谢的压力。一旦被对方查知你不是在致谢而是在应付致谢的压力，你就违背了荣耀原则了——因为你用行动在表示你认为对方并非无私(无私的话便不会非要谢意不可)而是出于牟取谢意才对你有利——你们的关系反而会**受损**。钱你也花了，饭你也请了，反而弄得损伤关系，这何其愚蠢？

很多人只是感受到致谢的必要，其实从未仔细想过到底该谢什么——或者干脆是因为从未做过这类思索而缺少得出这种答案的能力——这是**缺智慧。而很多人想得出为什么要致谢，却又私心以为谢意这种事代价太高——比如自己认定说被人救了一命就一定要卖身为奴，或者被那句“涌泉相报”吓住了——于是**不敢**称谢(掉水里被人救了，上岸之后瞅住机会悄悄消失，这样的事情并不少见)——这是缺勇气**。缺什么的勇气？不是缺承担补偿的勇气，而是缺**相信帮助你的人是无私的**的勇气。能不能准确而又毫无遮掩的把你的谢意说出来，这是一道关卡。卡住的人如果是少年，那么等于中了诅咒——在他之后漫长的一生中，他将会不断的为这种智慧和勇气的缺乏而承受损失。

在致谢的礼仪里，谢意的准确性和直接性就是庄重性的本质。比如有的人想要开点玩笑，为什么会显得不庄重？因为玩笑**不准确，**不直接**。而假如你可以不但说出你的谢意，并且能准确到将作为私人对朋友的感谢、作为下属对上司公事的感谢以及作为学生对老师教导的感谢等等条目分开，分别表述到严谨全面的程度，你会发现你的庄重性在增加——为什么？因为准确性**和**直接性**增加了。庄重并不是在说你要“板着脸”(表情严肃只是为了消除任何这是开玩笑的暗示，只是准确性的一部分)，而是说你要让人看到你的准确和直接;看到你对这件事考虑得有多深，又多么无畏的面对你考虑的结果——这两种表现，都能引发对方的敬意甚至敬畏。而所谓庄重，其实正是由对方的敬意和敬畏所定义的东西。

今天就说到这里。

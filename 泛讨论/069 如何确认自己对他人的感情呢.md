# 069 如何确认自己对他人的感情呢？

> Posted by 花生和尚 on 二 27th, 2012 in 杂论

**谈话者A：** 如何确认自己对他人的感情呢？

这问题是个表述混乱的问题，这个问法暗含了一种观点，就是爱必须要喜欢在先，喜欢到了一定程度就会爱。你问的事实上是**喜欢到什么程度就算是爱了**，是不是喜欢到日思夜想的程度，就算是爱了？

**谈话者A：** 不是。

是不是喜欢到不得到就要死的程度，就算是爱了？很多人都在这么想。

**谈话者A：** 感情是难以衡量的吗？

“如果我对她朝思暮想，我一定是爱上她了”。遗憾的是，这不对。本质上，和爱最接近的行为不是动物的求偶，而是另一个看起来几乎不相关的行为——“良臣择主而事”。

**谈话者A：** 良禽择木而栖。

一个臣子选择主公的过程正可以与之类比，他也要奉上服从的志愿，永远忍耐，永远相信，永不止歇。这不是来源，只是这的确也是服从的志愿，甚至，君臣名分比爱情名分更坚决和彻底。那么，现在我问你，臣子是如何选择主君的？回答我。

**谈话者A：** 能够尽吾才者，乃吾主也。

一名流浪骑士如何选择主君？你现在遇上了一个人，你怎么判断她可以做主君？

**谈话者A：** 能尽吾才者，乃吾主也。

只有如此吗？

**谈话者A：** 问能如此的君主，史上屈指可数。您认为不仅仅如此，那么请问还需要什么呢？

你要能真心认可她的价值观，你要检察她的志向，你要考虑她对她自己志向的诚意，你要考虑她的品性——是否宽大坚定勇敢而又谦卑。

**谈话者A：** 可是，爱的起源不是无法诠释的吗？这样岂不是从客观上承认了一种，爱人的标准吗？

你的生命，你当然有权利制定你的标准，要得到你的侍奉，她当然要有资格。**但是**，**你不需要喜欢她**。

**谈话者A：** **你不需要喜欢她**，换个方式说，是不是**她不需要讨好你**？

是，爱不是感觉出来的。不但如此，为了取得你的服务而讨好你的人是不能做你的主君的，能吗？该吗？威武不能屈，贫贱不能移，富贵不能淫，志向恢宏，胸襟广阔，这才是关键。你必定应该有不喜欢的，但是你却知道她是对的的地方。

**谈话者A：** 核心价值观需要相同。

你不能服务于一个杀人犯，她符合一切条件，并且你也看到了信号，那么就是她了，信号是指预兆。

**谈话者A：** 但是臣子和主君的关系，还会有平等么？

这个关系是互相的。

**谈话者A：** 互为君臣？

是的，互相臣服，但是你只能选择你这一半。

**谈话者A：** 还是这个问题：这是不是代表了爱，已经有标准了呢？

是，但是标准事实上是**懂得爱**，不但懂得 ，而且信奉。

**谈话者A：** ……爱不是没有来源的吗？

不的，这个标准并不决定爱，只是必须满足这个标准，你才能考虑建立这个关系，否则你就是所托非人。并且，你还尤其忌讳以你的好恶来进行选择，你喜不喜欢不重要，她有没有行你所信奉的道才重要，你很可能并不喜欢她的某些正确的行为。

**谈话者A：** 这个不重要，是吧？

是的，你要记住你是在选择主君，英明仁慈勇敢坚定，这才是你要的，不是他妈的美丽性感温柔水多。很多人所谓的爱，其实就是想做永久的嫖客，然后拼命 地展现荷包——“老纸有的是钱！”、“老纸有的是闲”、“老纸技术好，包高潮、包爽”，那是嫖宿关系，哪有什么爱？不要去考虑你有多想把她压在身下，考虑 她能不能做个好主公。

前者再强烈也不是爱，因此“喜欢到什么程度就算爱了”这个问题是个伪问题，答案是无论喜欢到什么程度都不算。表面上你很有冲动要为她做这做那，实际 上你很可能事实上是在付嫖资。一旦她不让你嫖，你就会觉得各种不值，你就觉得“你都不给我干，那我围着你干嘛”，嫖资付了，什么活都没有怎么行？将来年老 色衰了，或者不够色笑承欢了，立马就开始后悔。

**谈话者A：** 有问题要问，昨天你说“尽吾才者，乃吾主也”，选择对方，就是把对方当“吾主”，是这样么？

是。

**谈话者A：** 目的是“尽吾才”？

不，标准你另外定，但是性质上，她的确算是很接近主公。

**谈话者A：** 这只是心灵契合的一个标准而已，至于目的性，不讨论吗？

这不是心灵契合啊。

**谈话者A：** 那是什么？

这个过程不是心灵契合的过程，就是一个选择主君的过程。

**谈话者A：** 也就是能“尽吾才”？

反正你想清楚这是主君就行，什么标准你自己去决定。那是你们对主君的概念理解得太浅，当成是老板了，或者个人事业跳板。

**谈话者A：** 那主君是什么，从深度上讲？

君臣伦理啊——一个臣子应该怎么对主君，武士如何服从大名，骑士如何侍奉领主 。

**谈话者A：** 皇帝和臣子，是吧？

不，我始终没说皇帝。皇帝和子民的关系是另一回事，那和这个关系完全不同。主君和骑士之间是互有义务的，是有信条的，不是什么命令都能下的，也不是什么命令都必须服从的，这中间存在更高的义理。

举例来说，骑士发现主君背离上帝的道路，就可以宣布脱离效忠关系。你下的指令不能违背某些原则，违背了这个原则，我无法服从，不但无法服从，甚至会 解除关系。皇帝和臣民就没有这层限制。主君和骑士之间的关系很微妙，不违背这些原则，叫我死也可以;违背这些原则，给我金山银海也不行。

**谈话者A：** 爱情中对对方也可以这样？

是，爱人并非随便可捏的软骨头，你不当心，你就会失去的。他只是有服从的志愿，不是服从的义务。

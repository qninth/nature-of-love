# 054 学者的权利

> Posted by 花生和尚 on 二 27th, 2012 in 杂论

**谈话者A:**讨论问题前，双方是否要拥有普适性的定义？还是只要双方都统一就行？

两个都统一就行。但是，严格说来，这个定义应该本身有很大的普遍认同性。这个讨论越有意义，认同范围就越广。比如——我们两个可以约定圆就是离心率 为1的曲线。然后谈半天它的焦点，我们什么问题也没有。但是这些结论，对其他人就莫名其妙——因为其他人会觉得你们谈的不是圆形，明明是抛物线。这是其 一，**必也正名乎**。

其二，有的人会刻意通过扭曲定义来进行论辩。比如——将自由定义为心想事成，心里一想，自己就要能反重力，这种程度才算自由。然后通过这种定义，事实上消灭了自由——因为肯定谁也做不到心里一想就飞起来。

**谈话者A:**那这样能不能算得是真正的交流，或者辩论？

不，这是学者的权利。身为学者，在立论的时候有权选择自己的话语系统，有权定义自己的概念。但是，你的立论是为什么呢？你可以通过调整概念，来消灭 某些命题。比如，宣布绝对自由不存在。不信，请看我的绝对自由的定义。上帝那样才叫绝对自由，所以绝对自由就不存在。或者，真爱就一点都不能顾及自己，顾 及自己一点，你就不是真爱。而你一点都不顾及自己，你就活不下去。——**推出：**世界上没有真爱。

所以，我们需要理性看待这些结论，只能认为这样定义的这种自由或爱情不存在。头脑一定要清醒，不存在的，是**这种**绝对自由;不存在的，是**这种**真爱。这个逻辑论证没有问题，这个定义权你也有，这的确是不存在的。

但是，你只消灭了**这种**绝对自由，你只消灭了**这种**真爱。如果你们把**这种**两个字拿掉，那就完蛋了，拿掉，就出了重大问题。检查对方的论证 时，在定义和论证本身是否有问题之外，记住要加上这两个字。还必须记住：**这种**。不加这两个字，一个人的论证就变成了绝对真理，它的效力就会达到“个人 观点”所达不到的程度。

我随便举几个：**这种宗教**、**这种资本主义**、**这种有神论**、**这种风俗**、**这种资本家**。这个判断，前面就缺了**这种**两个字，就打倒了一 切宗教。因为你说，并非所有宗教都信仰人格神啊，然后你举例，一二三，他们都没有啊。**对方回答：**对不起，凡是不信仰人格神的，都称不上宗教。看到了吗，甚 至它的概念接受度也不低。逻辑本身无懈可击，但是它却有一个问题——那些不崇拜人格神的信仰体系呢？(比如中国的“天崇拜”)皇天在上，后土在下，臣嬴政 敬启者……那这算不算宗教呢？你可以把这排除在宗教之外，焚香、沐浴、更衣、斋戒七七四十九天……但是我个人认为这样去总结宗教(就是假设宗教以崇拜人格 神为本质标志)，你用词用得太浪费了——因为你必须另找一个更基本的词，去概括这两者的总集。

那个词又叫什么呢？这个更基本的概念，要同时包含崇拜人格神的宗教和不崇拜人格神的其它信仰体系。那么这个词该叫什么？你发现了吗，没词。但是这样的话，你的理论就很扭曲，很别扭，但是也不是不能成立，除非你再造一个，比如**信体**但是很丑陋。

你面临两种学术上的可行选择：
A:你创造一个词，**信体**，你说世界上有两种信体，一种是崇拜人格神的，叫宗教;一个是不崇拜人格神的，叫**非人格神信体**。
B:你可以说世界上有两种宗教，一种是崇拜人格神的，另一种崇拜非人格神。

当然A和B都成立，只是A为了非要让**一切宗教都崇拜一个人格神**这个命题成立，就付出了要创造两个新概念的代价，弄得七扭八弯。而这两个新的概念，用处何在呢？除了要赢得这场“是不是一切宗教都崇拜一个人格神”的辩论吗？

美是真的尺度，这是一个意图梳理自己理论体系的基本问题。同样真的时候，以美为尺度衡量你的选择。你就完全有能力言之成理，你的学术能力到达一定程 度，这非常容易。比如大量的民科们就是这样做的，他们并不全是荒谬的，他们的概念体系，往往能兼容科学，而且往往自洽。他们往往也需要大大的在理论自身的 美感上下重大的功夫。为什么要这样做呢？——因为让人记住更多的用处不大的概念，或者要改动太多的原有概念的理解，是不好的。

**爱是服从的志愿**，身为学者，你是在服从大众求真的志愿，但这志愿不是仅仅真实就足够了，同样要简洁、代价小，因为你要顾惜别人的代价，这是爱。

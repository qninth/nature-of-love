# 071 关于“告假”

> Posted by 花生和尚 on 二 27th, 2012 in 杂论

**谈话者A：** 我想请教一下关于**告假**，如果过于爱的过于痛苦，可以告假吗？

可以。

**谈话者A：** 那么具体怎么说合适呢？

你想要怎么告假呢？暂时终止关系？还是暂时别提什么事？还是暂时只通电话不见面？

**谈话者A：** 暂时取消亲密关系。可以断绝一切联系吗？

首要的一点是：你要想清楚，可以有很多选择。从几乎看不出什么区别到暂时完全中断联系，可以有很多选择。

**谈话者A：** 嗯，能有哪些选择呢？

比如暂时别提什么事，但是其他一切照旧;或者减低见面频率;或者不见面只通讯;或者只做QQ通讯;或者连QQ联系都降低频率;或者暂时完全切断联系。你有很多强度不同的选择。

**谈话者A：** 但是如果到了，一联系，就想起的情况下，怎么办？一联系就痛苦，甚至不联系都痛苦。可是我爱她，迫使我服从她，但联系她，又让我痛苦，这样的两难如何处理？

首先，你有很多级别的告假方式。你可以看到他们的疏离度是逐渐增大的，现在就出现问题了。你能不能一下选择强度最大的告假方式？比如，一下选择暂时切断一切联系？

**谈话者A：** 荣耀原则？相信对方能承受？

不。这和荣耀原则无关，不要忘了告假的目的。告假不是为了你的舒适，是为了避免你的痛苦造成对方的困扰。是为了她，不是为了你自己。

**谈话者A：** 怎么解释？

你对某些事情有本能的痛苦，这不是你自己可以控制的，至少目前还不能很好的控制。

**谈话者A：** 告假不是为了避免这些痛苦吗？

这才是有爱还要告假的理由——不是为了避免，是为了战胜这些痛苦。

**谈话者A：** 为了战胜这些痛苦，更好的继续爱？

是。

**谈话者A：** 可是告假本身会不可避免地造成伤害吧？

所以你要努力的选择最小幅度的告假方式，尽可能的不要让对方感受到疏远。始终努力试图为她承受最大限度的痛苦，尽量保持为她提供最大的服务。比如你 的承受力是100，你现在承受的是120，你只能告20的假，而不是告120的假，在你告了20的假之后，承受着那100。承受久了就会变强，变得能承受 110，然后是120，然后回到若无其事的状态。你承受得越多，你强壮得越快。

如果你一下告假到零，那么你打算什么时候才回到120呢？你根本什么都没承受，你根本不会变强，永无回到120的机会。客观来说，你事实上就是打着 主意要回避到零，然后等着这120自己消散。不消散，你就永远告假下去。那么，这不是告假，这就是撤退了，不要假借告假之名。我说得非常透彻，你比较一下 两个模式。你就会发现只有前者才是告假，后者不是。

告假不是回避痛苦，告假只是把抓举变成了挺举，以便举起抓举顶不住的沉重。这是很残酷的选择，但是，这是勇气的选择。残酷留给自己，甜蜜留给她。并且默不做声，不求闻达。

基于爱，你告假只能从最小幅度开始。只有在这个幅度的确证明不够的前提下才能申请更大幅度，**幅度等于疏离度乘以告假时长**。比如暂时不要见面你告假一个月和切断一切联系你告假一天。实际上后者幅度更小 。

**谈话者A：** **不够**的标准是什么？

不够的意思是你仍然承受不住。

**谈话者A：** 怎么判断我是否承受的住。

你能保持不抱怨，就是能承受。你忍不住发飙或者冷嘲热讽，就是没承受住。我只是沿着爱的本意顺着逻辑推演。爱是通神之路，当然不容易。但是哪个是爱是很分明的，你自己可以看到。

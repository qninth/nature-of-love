# 割肉饲虎

在本群默认任何观点说出来就可以评论。这不算粗暴干涉，因为本群是讨论群。一说话就等于默认接受讨论，等于已经发出邀请，只不过别人并没有义务肯定要接。

你们经常看到我问人这是表达一下情绪还是有问题要问，那是因为对方的叙述方法不像是在求讨论。按道理应该叫他闭嘴，不过其情可悯。比如哭着问我该怎么办，却又拒绝提供详情;很坚持事情不是你想的那样，又不说到底是怎么样。除了这种默认的讨论场合，别的场合，最好嘻嘻哈哈频频点头，不置可否。

只除了一种情况：你有心以身饲虎。发了菩萨愿，欲度一切人。

擅自批评是一种恶，要遭惩罚的。别觉得人家后来攻击你很冤枉，你说之前就要知道那是罪有应得。你觉得自己受点罪或许可以对别人有点好处是一个好理由的话，可以说。但是**不要觉得这很伟大，也不要觉得自己很忍辱负重。你做不到这两个不要**，你事实上其实是在享受自居菩萨的快感。那你就要有肉割尽，虎未足的准备了——别人毫不领情，而且会要你命。你的"劝导"几乎总是从客观上一钱不值，因为你这境界说实话也提不出啥好观点。

为啥呢？

因为你在享受菩萨快感。这是很爽的。既然这是以过瘾为诉求，你肯定不管三七二十一，看到机会就上。因为过瘾优先嘛，机会岂容错过？要是反而被老虎所伤。。。 啊啊啊，请看我多么伟大～爽死了有木有？！要是心里不爽呢，你又占了道德高地，可以吼人。"nnd小兔崽子老纸是为你好！！""说得对不对的 你也不能用这种态度对我！！"

很多父母对自己的子女，开始是菩萨愿，后来变成过菩萨愿的瘾了。

割肉饲虎，本来不该对虎有任何期待。人家是虎，吃肉了你要人家咋样？现在要人家感恩，要人家识货，要人家懂礼貌，要人家。。。。下回你只管割，看老纸吃不吃！老纸直接要你命！咬死了扔野狼堆！老纸回家漱口，一口都不吃！吼吼吼～

不要搞错，菩萨愿是高尚的东西，被批评的是过菩萨瘾。菩萨是割了肉还被咬死也觉得自己罪有应得的，菩萨瘾才咽不下这口气。

**谈话者A:** 那菩萨求的是什么？成佛吗？

无求。求地狱空。己身空无一物，有何必求？

只有他人是实在的。他人的实在，不是我认为他实在。事实上，我认为他人也是空。但是他人自认是实，因此割肉饲之。我割肉以示我之空，我无损而人有益。你受了这益，早日万贯家财，便可以早知万贯家财是空。

# 看片会《千年女优》

这片子里面最有意思的要点，在于那个老婆婆的话：

我爱你入骨，我恨你入骨。

女主角所拥有的东西是爱？其实不是。她所拥有的东西实际上是一种执着，只不过是以爱为名罢了。

为什么说命运对她爱之入骨？就是因为命运给了她这份执着------【执着的能力，极近于爱的能力】。无论你执着的是什么，只要你能做到如此的数十年一贯的、奋不顾身的程度，它都必定能造就你。这就是为什么后来那个女演员说：我嫉妒你，你在追逐的时候永葆着你的青春，而我只能不断的去演更老的角色。这份执着造就了她。只要她一天处在这个执着的状态中，她就自然得到所有人的关注，得到所有人的爱护，她自己也会处在坚不可摧、无所畏惧的状态。

这样的状态非常的美丽和性感，但是命运又同时诅咒了她------因为她所执着的东西，只有爱的名义，而无爱的实质。于是她成功了，但是这成功却没有实际的意义。前者是命运的宠爱，后者是命运的诅咒。前者是爱你入骨，后者是恨你入骨。这就是那个老婆婆的两句话的意思，她自己在那次钥匙失落之后，发觉了这一点。那次最后的表演之后，她一下明白了，于是这个执着就戛然而止了。毕竟是空的，假借服从的志愿，你将获得极大的力量，但是假如你假借的其实只是一种名义，你便很可能获得这种"无意义的巨大成功"。自己能骗自己多久呢？

回头再来看这样一点：【女主极其的孤独】。

事实上，这么多年她生活在一个空无一人的世界里。你可以看到这片子里，这位女主几乎并不与其他人对话，她几乎完全没有注意到别人在想什么，完全没有注意到自己身边在发生什么。谁喜欢她，谁不喜欢她，谁在帮助她，谁在需要她，她一概都没去看。总是别人在对她说话，她几乎不对别人说话。她的眼睛，只盯在那个影子上面，盯在那个"亮光"上面，一旦熄灭，就会发现自己【错过了一切】。她太骄傲，太任性，又非常不幸的是，她又太幸运。幸运到现实允许了她一直骄傲到了那样的年纪，这是一种不幸的幸运。这就好像一个小孩子，坚定的认为世界就是以他自己为中心的，偏偏他还生为豪门贵公子，家里的钱财还恰好就够他挥霍到三四十岁的，这些钱财，对这人就是这种"不幸的幸运"。这种"不幸的幸运"，恰恰也正是那两句话：我爱你入骨，我恨你入骨。

这女主假设真的想要摆脱这种命运，她只需要【真的去爱】，而不是去【爱"爱某个人"的名义】。说穿了这位是中了"一见钟情，从一而终"这种"完美模式"的毒，她就是高傲到非要这种完美不可，比这差一点的本小姐都绝对没兴趣。日久生情这种弱爆了，心里记挂着一个再现实中又爱一个这种也逊爆了，可惜，【爱最恶骄傲】。你抱着这种傲气，自然就与爱无缘。抱着多久，你就错过多少。到了人到中年终于醒悟，你选择隐居，那么你就其实还抱着这个傲慢。你知道自己错了，但是你【拒绝改错】，因为选择隐居，意味着就算我知道了，我也不要去爱人.这实际上仍然是高傲无比，那么你就"很满足"的孤老山林吧，一生不知悔改的王八蛋，活该!你事实上把自己的一生都浪费掉了,浪费在不断的满足自己的良好自我感觉上了,浪费在不断的维护自己在自己面前的面子上了。这个面子，于人于己都是大害。即使中年醒悟，你也不该浪费那后三十年，不是吗？

至于说那位采访者，他也并不是爱，他喜爱的是一种爱的游戏。为什么这么说？因为他【经常沉浸在自己的幻想里面出不了戏】。如果是爱，不会存在这种出不了戏的状况，不会人家走了自己还在说台词说得很high。尖刻一点说，这不是爱，这是自慰，这是拿对方当自慰器。只是这个自慰器超好的，所以很激动很high，【屌丝们追"女神"，就是在拿"女神"们当超一流自慰器】。超肤感の充气人形！大兴奋超热売中！可惜究极昂贵。

最后总结一下：

1. 执着是必备的东西。

2. 爱是最强的------甚至是唯一的------执着的根基。

3. 对任性的人，幸运本身就是不幸。

4. 骄傲的人无时无刻不是在自戕和浪费生命。

5. 女神们别接受逆袭------屌丝们是要拿你们当自慰器。回头你老是潮吹不了他会以为你坏掉了，会吵着要退货的。

# nature-of-love


本目录收录了关于爱情的哲学讨论与实践指导文档，分为三个主要部分：

## 目录

### 1. [泛讨论](泛讨论/)
- 章节数：150个
- 内容：关于爱情本质、相处之道、情感问题等方面的深入讨论
- 包含话题：爱的定义、选择爱人、处理愤怒、分手与复合、信任与背叛等

### 2. [泛讨论补充部分](泛讨论补充部分/)
- 章节数：21个
- 内容：对泛讨论部分的补充和延伸
- 特色：包含多场看片会和读书会的讨论记录
  - 看片会：《千年女优》《乱世佳人》《了不起的盖茨比》《与莎莫的500天》等
  - 读书会：《杜十娘怒沉百宝箱》

### 3. [爱的实践部分](爱的实践部分/)
- 章节数：72个
- 内容：系统性的爱情实践指导手册
- 结构：
  - 第1章 独立
  - 第2章 待人接物
  - 第3章 立志
  - 第4章 追求

## 文档说明

- 所有文档均已从原始Word文档转换为Markdown格式
- 图片资源统一存放在 [img](img/) 文件夹中
- 文档格式已优化，包括：
  - 谈话者姓名加粗显示
  - 使用标准的Markdown列表格式
  - 引用格式用于斜体内容转换
  - 统一的POSTED信息和整理者信息格式
